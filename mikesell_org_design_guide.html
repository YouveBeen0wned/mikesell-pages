Heading Hierarchy (from live HTML)
H1
"Not me. Us." — Hero headline. Large, bold, center-aligned. Likely 48–64px on desktop. Wix default: Playfair Display or similar serif for hero text.
H2
"About Mike", "This is our movement." — Section headers. ~32–40px. Usually same family as H1 or bold sans.
H4
"Early Life", "Today", "The Future" — Subsection labels. ~20px. Often a different weight or color from body.
H5
Subheadlines and CTA support text. ~16–18px. Used for supporting context under CTAs.
p
Body copy. ~16px, line-height ~1.7. Paragraph text in bio and movement sections.

Wix CDN URL Pattern
All images are served from static.wixstatic.com with Wix's transform API baked into the URL. You do not need to download or re-host them — reference the URLs directly.
/* Logo PNG (transparent bg) */ https://static.wixstatic.com/media/8f30d6_4602a9... /fill/w_182,h_81,al_c,q_85,enc_avif,quality_auto/... /* Hero image */ https://static.wixstatic.com/media/8f30d6_ef169b... /fill/w_621,h_502,al_c,q_80,enc_avif,quality_auto/... /* Jacksonville bridge */ https://static.wixstatic.com/media/8f30d6_86dfb5... /fill/w_980,h_626,al_c,q_85,enc_avif,quality_auto/...
Image Parameters You Can Control in the URL
w_
Width in px. Change this to resize the image.
h_
Height in px. Leave out for auto-height.
q_
Quality (1–100). 80–85 is good for web.
al_c
Alignment: center. Options: tl, tr, bl, br, c
enc_avif
Format: AVIF. Change to enc_webp or enc_jpg if needed for older browser support.
NOTE Add loading="lazy" to all img tags below the fold. Add alt text for accessibility and SEO.
Wix HTML Embed Constraints
1 Wix embeds HTML via an iFrame. Your code runs in a sandboxed iframe — no access to parent window or Wix's CSS variables.
2 You must include all your own styles. Do not rely on Wix's stylesheet inside an embed block.
3 Height must be set manually on the Wix embed element, or use postMessage to resize. Default iframe does not auto-expand.
4 External fonts must be imported inside the embed's own style block.
LIMIT No form POST submissions to external servers without CORS headers configured on your server.
OK JavaScript, fetch(), localStorage, and CSS animations all work inside Wix embeds.
